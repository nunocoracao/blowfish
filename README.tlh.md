### Blowfish Tools lo'taHvIs tIn ghIch

> **Mash:** **Node.js**, **Git** je **Hugo** lo'taH, Hugo project chentaH joq.

CLI chu' ghaj Blowfish Tools. Hugo project chen, pat ghIch vIgh. beta 'oH, [Qaghmey vIgh](https://github.com/nunocoracao/blowfish-tools).

CLI pat vIgh npm lo'taHvIs:
```shell

```

ghIch SeHmeH `blowfish-tools` yIlo', chenghach pat ghojmeH.
```shell

```

Hugo project chu' chenmeH, theme chenmeH je, `blowfish-tools new` yIlo'. CLI De' yILegh.
```shell

```

### git submodule lo'taHvIs tIn ghIch

> **Mash:** **Git** je **Hugo** lo'taH, Hugo project chentaH joq.

1. Hugo project daq, git yIlo':

   ```shell
   git init
   ```

2. Blowfish git submodule yISeH:

   ```shell
   git submodule add -b main https://github.com/nunocoracao/blowfish.git themes/blowfish
   ```

3. De'wI' pat qoD, `hugo.toml` yIteq, Hugo chenlu'. Theme daq `*.toml` SeHmey `config/_default/` daq yIqon.

   Theme daq SeHmey Hugo cache daq vIgh, joq GitHub daq [SeHmey yItIgh](https://github.com/nunocoracao/blowfish/releases/latest/download/config-default.zip).

4. De'wI' pat SeHmeH [tIn ghIch](https://blowfish.page/docs/getting-started/) yIlaD.

### Hugo lo'taHvIs tIn ghIch

> **Mash:** **Go** je **Hugo** lo'taH, Hugo project chentaH joq.

1. Hugo project daq, Hugo Modules yIlo':

   ```shell
   hugo mod init github.com/<username>/<repo-name>
   ```

2. `config/_default/module.toml` yIchen, ghItlhvam yIchel:

   ```toml
   [[imports]]
   path = "github.com/nunocoracao/blowfish/v2"
   ```

3. `hugo server` yIlo' server daq, theme chenlu' pat.

4. De'wI' pat qoD, `hugo.toml` yIteq, Hugo chenlu'. Theme daq `*.toml` SeHmey `config/_default/` daq yIqon.

   > **Mash:** `module.toml` yIqoq, chenlu'!
   
   Theme daq SeHmey Hugo cache daq vIgh, joq GitHub daq [SeHmey yItIgh](https://github.com/nunocoracao/blowfish/releases/latest/download/config-default.zip).

5. De'wI' pat SeHmeH [tIn ghIch](https://blowfish.page/docs/getting-started/) yIlaD.
