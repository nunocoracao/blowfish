## Функције

- Потпуно респонзиван изглед изграђен помоћу Tailwind CSS 3.0
- Више шема боја (или потпуно прилагодите сопствену)
- Тамни режим рада (присилно укључен/искључен или аутоматско пребацивање са корисничким прекидачем)
- Високо прилагодљива конфигурација
- Firebase интеграција за подршку динамичким подацима
- Бројач прегледа и механизам за лајковање
- Повезани чланци
- Вишеструки изгледи почетне странице
- Подршка за више аутора
- Серијали чланака
- Разврставање чланака на основу датума и тежине (weight)
- Зен режим рада за читање чланака
- Флексибилност са свим врстама садржаја, таксономијама и менијима
- Менији у заглављу и подножју
- Угнежђени менији и подменији за навигацију
- Садржај (Table of Contents) са могућношћу помицања (scroll)
- Вишејезична подршка, укључујући подршку за језике који се пишу здесна налево (RTL)
- Могућност повезивања на објаве на спољним веб сајтовима
- Подршка за неколико кратких кодова (shortcodes) попут галерије, временске линије, GitHub картица и вртуљака (carousels)
- Синтакса за GitHub упозорења (Alerts), 15 врста, са подршком за скупљање/ширење
- Интеграција за "Buy me a coffee"
- Претрага странице на страни клијента коју покреће Fuse.js
- Дијаграми и визуелизације помоћу Mermaid.js
- Графикони помоћу Chart.js
- Интеграција за TypeIt
- YouTube уградња са побољшањима перформанси
- Математичка нотација помоћу KaTeX-а
- SVG иконе из пакета FontAwesome 6
- Аутоматска промена величине слика помоћу Hugo Pipes-a
- Сидра за наслове, садржај, копирање кода, дугмад, беџеви и још много тога
- HTML и Emoji подршка у чланцима 🎉
- SEO прилагођено са линковима за дељење на друштвеним мрежама
- Подршка за Fathom Analytics и Google Analytics
- Подршка за RSS сажетке, Фавиконе и коментаре
- Напредна прилагођавање помоћу једноставних Tailwind дефиниција боја и стилова
- Оптимизовано за перформансе и приступачност са савршеним Lighthouse резултатима
- Потпуно документовано са редовним ажурирањима

## Инсталација

Blowfish подржава неколико метода инсталације - као git подмодул (git submodule), Hugo модул (Hugo Module) или као потпуно ручну инсталацију.

Детаљна упутства за сваку методу могу се пронаћи у документацији за [Инсталацију](https://blowfish.page/docs/installation). Препоручујемо да консултујете документацију ради најједноставнијег постављања. Испод се налази водич за брзи почетак помоћу подмодула ако користите git, или помоћу Hugo модула ако сте већ сигурни у инсталацију Hugo тема.

### Брзи почетак помоћу Blowfish алата (Blowfish Tools)

> **Напомена:** Проверите да ли имате инсталиране **Node.js**, **Git** и **Hugo** и да ли сте креирали нови Hugo пројекат пре него што наставите.

Управо смо лансирали нови CLI алат који ће вам помоћи да започнете са Blowfish-ом. Алат ће креирати нови Hugo пројекат, инсталирати тему и поставити конфигурационе датотеке теме уместо вас. Још увек је у бета фази, па вас молимо да [пријавите све проблеме на које наиђете](https://github.com/nunocoracao/blowfish-tools).

Инсталирајте CLI алат глобално помоћу npm-а (или другог управљача пакетима):
```shell
npm i -g blowfish-tools
```

Затим покрените наредбу `blowfish-tools` за покретање интерактивног режима рада који ће вас водити кроз процес креирања и конфигурације.
```shell
blowfish-tools
```

Такође можете покренути наредбу `blowfish-tools new` како бисте креирали нови Hugo пројекат и инсталирали тему одједном. Проверите CLI помоћ за више информација.
```shell
blowfish-tools new mynewsite
```

### Брзи почетак помоћу git подмодула (git submodules)

> **Напомена:** Проверите да ли имате инсталиране **Git** и **Hugo** и да ли сте креирали нови Hugo пројекат пре него што наставите.

1. Из директоријума вашег пројекта иницијализујте git:

   ```shell
   git init
   ```

2. Конфигуришите Blowfish као git подмодул:

   ```shell
   git submodule add -b main https://github.com/nunocoracao/blowfish.git themes/blowfish
   ```

3. У коренском директоријуму вашег веб сајта обришите датотеку `hugo.toml` коју је генерисао Hugo. Копирајте `*.toml` конфигурационе датотеке из теме у ваш `config/_default/` директоријум.

   Ове конфигурационе датотеке теме можете пронаћи у Hugovom директоријуму привремене меморије (cache directory) или [преузмите копију](https://github.com/nunocoracao/blowfish/releases/latest/download/config-default.zip) са GitHub-а.

4. Следите упутства за [Почетак рада (Getting Started)](https://blowfish.page/docs/getting-started/) како бисте конфигурисали свој веб сајт.

### Брзи почетак помоћу Hugo модула

> **Напомена:** Проверите да ли имате инсталиране **Go** и **Hugo** и да ли сте креирали нови Hugo пројекат пре него што наставите.

1. Из директоријума вашег пројекта иницијализујте Hugo модуле:

   ```shell
   hugo mod init github.com/<username>/<repo-name>
   ```

2. Креирајте датотеку `config/_default/module.toml` и додајте следеће:

   ```toml
   [[imports]]
   path = "github.com/nunocoracao/blowfish/v2"
   ```

3. Покрените свој сервер помоћу наредбе `hugo server` и тема ће се аутоматски преузети.

4. У коренском директоријуму вашег веб сајта обришите датотеку `hugo.toml` коју је генерисао Hugo. Копирајте `*.toml` конфигурационе датотеке из теме у ваш `config/_default/` директоријум.

   > **Напомена:** Немојте преписати датотеку `module.toml` коју смо претходно креирали!
   
   Ове конфигурационе датотеке теме можете пронаћи у Hugovom директоријуму привремене меморије (cache directory) или [преузмите копију](https://github.com/nunocoracao/blowfish/releases/latest/download/config-default.zip) са GitHub-а.

5. Следите упутства за [Почетак рада (Getting Started)](https://blowfish.page/docs/getting-started/) како бисте конфигурисали свој веб сајт.

### Инсталирање ажурирања теме

Како излазе нове верзије, тему можете ажурирати помоћу Hugo-а. Једноставно покрените `hugo mod get -u` из директоријума вашег пројекта и тема ће се аутоматски ажурирати на најновију верзију.

Детаљна [упутства за ажурирање](https://blowfish.page/docs/installation/#installing-updates) доступна су у документацији.

## Допринос пројекту

Очекује се да ће се Blowfish с временом развијати. Намеравам да наставим са додавањем нових функција и уношењем промена према потреби.

Слободно се јавите ако наиђете на проблеме или ако имате предлоге за нове функције које бисте желели да видите.

- 🐛 **Пријаве грешака и проблеми:** Користите [GitHub Issues](https://github.com/nunocoracao/blowfish/issues)

Ако можете да исправите грешку или имплементирате нову функцију, ваши Pull Request-ови (PR) су више него добродошли. Сазнајте више у [смерницама за допринос пројекту](https://github.com/nunocoracao/blowfish/blob/main/CONTRIBUTING.md).
